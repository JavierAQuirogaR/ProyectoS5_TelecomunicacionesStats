# ProyectoS5_TelecomunicacionesStats
Análisis estadístico de las telecomunicaciones Megaline.

# Propósito
Determinar cuál de los planes ofrecidos presenta la mayor utilidad
# DataSet
Se utiliza un conjunto de datos conformado por el nombre del plan, la fecha de realización de la llamada, la duración de la llamada y la cantidad de bytes disponibles para mensajes o transmisión de datos.
# Resultados
Se determina que el Plan Megaline Light es el que presenta mayor rentabilidad.
